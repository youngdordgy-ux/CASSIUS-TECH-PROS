👑 ABOUT THE BOT

CASSIUS TECH PROS is a WhatsApp automation project built to make messaging more interactive, entertaining and convenient.

Designed with powerful commands, automation tools, group management, media features and entertainment commands.

</p>🛠️ INSTALLATION

Make sure Node.js and Git are installed.

git clone YOUR_REPOSITORY_LINK
cd YOUR_REPOSITORY_NAME
npm install

Configure your settings and environment variables, then start the bot:

node main.js

⚙️ CONFIGURATION

Edit "settings.js" to configure:

- Bot name
- Owner name
- Owner number
- Command mode
- Bot version

Keep API keys, authentication credentials and session files private.
